# Evidence scope

No raw prediction arrays, model checkpoints, provider responses, or sealed-test
payloads are included in this anonymous package.  The public `results/` files
are faithful transcriptions of the latest manuscript tables.  They are not
silently presented as independently recomputed evidence.

The full development workspace contains historical and sometimes conflicting
artifacts.  Those files remain outside this release.  A private reconciliation
report records the inclusion and exclusion decisions and must never be copied
into this repository or its release archive.

# Dataset access and redistribution

The anonymous package does not redistribute raw benchmark data.  The
manuscript names the following task families:

- BBBC021, BBBC036, and BBBC047 morphology from the Broad Bioimage Benchmark
  Collection;
- CPG0016 Cell Painting morphology from the JUMP/Cell Painting data release;
- LINCS L1000 perturbation-response profiles.

Before any full rerun, obtain the exact public release and license from the
official provider, verify the version and checksum recorded by the experiment
lineage, and materialize the documented split and target-order manifests.  The
anonymous release does not guess a download URL or checksum when the final
lineage is not present.  See `dataset_manifest.csv` for the required fields
and the current packaging decision.
